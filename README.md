```markdown
# 📈 StockPulse

A modern stock news aggregation platform that combines financial news, market sentiment, and stock market data into a single dashboard.

![React](https://img.shields.io/badge/React-18-blue)
![Node.js](https://img.shields.io/badge/Node.js-18+-green)
![Express](https://img.shields.io/badge/Express.js-Backend-black)
![MySQL](https://img.shields.io/badge/MySQL-Database-orange)
![License](https://img.shields.io/badge/License-MIT-blue)

## Overview

StockPulse aggregates financial news from multiple sources and presents it through a clean, modern interface. Users can browse market news, filter articles, track sentiment trends, and monitor stock-related updates from Indian and global markets.

### Key Highlights

- 📰 Multi-source financial news aggregation
- 📊 Market sentiment classification
- 🔍 Advanced search and filtering
- 🇮🇳 Indian market coverage (NSE/BSE)
- 🇺🇸 US market coverage (NASDAQ/NYSE)
- 📱 Responsive dashboard design
- ⚡ Fast React + Vite frontend
- 🗄️ MySQL-powered backend
```

````markdown
## Local Development

### Clone Repository
````

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
